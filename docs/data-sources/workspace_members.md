# ory_workspace_members (Data Source)

Lists the members of an Ory Network workspace. Pending invites are not members. If `workspace_id` is not set, the provider's `workspace_id` is used.

-> **Plan:** Available on all Ory Network plans.

~> **Authentication:** The Ory Console API accepts member requests only from a signed-in Console user, and answers a workspace API key with HTTP 401. Run `ory auth` and set `workspace_api_key` to the access token, as [Managing a project without a workspace API key](https://registry.terraform.io/providers/ory/ory/latest/docs#managing-a-project-without-a-workspace-api-key) describes.

## Example Usage

```terraform
# List the members of the workspace from the provider configuration.
data "ory_workspace_members" "current" {}

output "workspace_owners" {
  value = [for m in data.ory_workspace_members.current.members : m.email if m.role == "owner"]
}
```
