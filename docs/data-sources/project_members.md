# ory_project_members (Data Source)

Lists the members of an Ory Network project.

The list includes the members of the workspace that the project belongs to. Ory reports one role per person, the strongest one, and `source` names the scope that gives it: `project` or `workspace`. On a tie, the workspace role wins. Pending invites are not members. If `project_id` is not set, the provider's `project_id` is used.

-> **Plan:** Available on all Ory Network plans.

~> **Authentication:** The Ory Console API accepts member requests only from a signed-in Console user, and answers a workspace API key with HTTP 401. Run `ory auth` and set `workspace_api_key` to the access token, as [Managing a project without a workspace API key](https://registry.terraform.io/providers/ory/ory/latest/docs#managing-a-project-without-a-workspace-api-key) describes. The user must be an owner or a developer of the project.

## Example Usage

```terraform
# List the members of the project from the provider configuration.
data "ory_project_members" "current" {}

# People with a role on the project itself, not through the workspace.
output "direct_project_members" {
  value = [for m in data.ory_project_members.current.members : m.email if m.source == "project"]
}

# List the members of another project.
data "ory_project_members" "other" {
  project_id = "00000000-0000-0000-0000-000000000000"
}
```
